JPA Web Application Example (Spring 7 & WildFly)
============
This example is based on Jakarta EE 11, JPA 3.2, Spring Framework 7.0.8, Java 21, and PostgreSQL 18.4. It is configured for deployment on WildFly 40.

## Building
```shell
./gradlew build
```
`jpa-webapp-spring.war` will be created in `build/libs`.

To extract the PostgreSQL JDBC driver JAR into `build/postgresql/postgresql.jar`:
```shell
./gradlew copyPostgresqlJar
```

## Available API Endpoints
After deploying the WAR application to WildFly 40, access the following URLs:

- **List All Accounts:**
  `http://localhost:8080/jpa-webapp-spring/webapi/account/list`
- **Create Account:**
  `http://localhost:8080/jpa-webapp-spring/webapi/account/new?id=100&balance=500.00`
- **Transfer Balance:**
  `http://localhost:8080/jpa-webapp-spring/webapi/account/transfer?accountFrom=100&accountTo=200&amount=50.00&sleep=0`
- **List All Transactions:**
  `http://localhost:8080/jpa-webapp-spring/webapi/transaction/list`

## PostgreSQL 18.4 Setup

### Step 1. Create the user and database
Connect to PostgreSQL 18.4 as a superuser (e.g., `postgres`) and execute:

```sql
CREATE USER user1 WITH ENCRYPTED PASSWORD 'password';
CREATE DATABASE mydb OWNER user1;
```

> **Note:** Setting `user1` as the owner ensures that Hibernate's schema generation can create tables in the `public` schema.

### Using Docker
To run PostgreSQL 18.4 with Docker:

```shell
docker run -d --name postgres \
  -e POSTGRES_USER=user1 \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=mydb \
  -p 5432:5432 \
  postgres:18-alpine
```

## WildFly 40 Setup

Follow these steps in order to set up WildFly 40 for this application.

### Step 1. Add an application user (server stopped)

```shell
$WF_HOME/bin/add-user.sh -a -u user1 -p password -g guest
```

### Step 2. Install the PostgreSQL JDBC driver module (server stopped)

You can use the driver JAR generated by `./gradlew copyPostgresqlJar` at `build/postgresql/postgresql.jar` (or specify your local `postgresql-42.7.13.jar`).

```shell
$WF_HOME/bin/jboss-cli.sh \
  --command="module add --name=org.postgresql --slot=main \
    --resources=/path/to/postgresql-42.7.13.jar \
    --dependencies=jakarta.transaction.api"
```

### Step 3. Start the server

Start the server in standalone mode. Keep this terminal open.

```shell
$WF_HOME/bin/standalone.sh
```

Wait until you see `WFLYSRV0025: WildFly ... started` in the log before proceeding.

### Step 4. Register the JDBC driver (server running)

Open a new terminal and run:

```shell
$WF_HOME/bin/jboss-cli.sh --connect \
  --command='/subsystem=datasources/jdbc-driver=postgresql:add( \
    driver-module-name="org.postgresql", \
    driver-class-name=org.postgresql.Driver, \
    driver-xa-datasource-class-name=org.postgresql.xa.PGXADataSource)'
```

### Step 5. Add the Datasource (server running)

```shell
$WF_HOME/bin/jboss-cli.sh --connect \
  --command="data-source add --name=MyDB \
    --driver-name=postgresql \
    --jndi-name=java:jboss/datasources/MyDB \
    --connection-url=jdbc:postgresql://localhost:5432/mydb \
    --user-name=user1 --password=password \
    --max-pool-size=25 --blocking-timeout-wait-millis=3000 \
    --enabled=true"
```

### Step 6. Deploy the application (server running)

```shell
$WF_HOME/bin/jboss-cli.sh --connect --command="deploy build/libs/jpa-webapp-spring.war"
```

To update an already deployed application:

```shell
$WF_HOME/bin/jboss-cli.sh --connect --command="deploy build/libs/jpa-webapp-spring.war --force"
```

### Stopping the server

Press `Ctrl + C` in the terminal where the server is running.

For further information, read [WildFly Documentation](https://docs.wildfly.org/).
